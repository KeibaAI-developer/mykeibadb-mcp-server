# feat: 調教データAPI（get_uma_chokyo / analyze_chokyo_debut_seiseki）

## 概要

馬ごとのウッドチップ・坂路調教データを取得する `get_uma_chokyo` と、
デビュー前の調教条件を満たした馬のデビュー後勝利率を集計する `analyze_chokyo_debut_seiseki` を追加した。

## 変更内容

### 既存ファイルの変更

- `src/mykeibadb_mcp_server/high_level_api.py`: 調教データAPI2関数とヘルパー関数を追加
  - `get_uma_chokyo`: 馬名部分一致でウッドチップ・坂路調教レコードを取得。`before_debut=True` でデビュー前のみ絞り込み可能
  - `analyze_chokyo_debut_seiseki`: 指定期間デビュー馬のうち調教条件（ウッド6F/ラスト1F、坂路4F/ラスト1F、トレセン区分）を満たす馬の勝利率を集計。動的CTEでウッド・坂路の複合条件を構築
  - `_fmt_time4` / `_fmt_lap3`: 4桁・3桁タイム文字列（0.1秒単位）を秒表記に変換するプライベートヘルパー
- `src/mykeibadb_mcp_server/server.py`: MCPツールラッパー2関数を追加
  - `tool_get_uma_chokyo` / `tool_analyze_chokyo_debut_seiseki`

## テスト内容

### 既存ファイルの変更

- `tests/test_high_level_api.py`: 新規2関数のテストを9件追加
  - `get_uma_chokyo`: 正常系3件（タイム変換・件数、馬名マッチなし、デビュー前フィルタSQL確認）、準正常系1件（DBエラー）
  - `analyze_chokyo_debut_seiseki`: 正常系4件（ウッド条件、total=0のゼロ除算、ウッド+坂路INTERSECT確認、条件なし）、準正常系1件（DBエラー）
