# feat: 集計APIにXコースn週目フィルタを追加

## 概要

`analyze_waku_seiseki` などの集計API5関数に `course_kubun`（コース区分）と `week_in_course`（コース使用開始からの週番号）パラメータを追加した。
JRA競馬場ではコースを開催ごとに切り替えるため、「東京芝CコースX週目」のような条件での集計が可能になる。

## 変更内容

### 既存ファイルの変更

- `src/mykeibadb_mcp_server/high_level_api.py`: 集計API5関数に `course_kubun`・`week_in_course` パラメータを追加
  - 両パラメータが同時指定された場合のみ有効（片方だけでは無効）
  - PostgreSQL CTE（WITH句）でコース週番号を算出して対象開催日を絞り込む
  - `_build_course_week_cte` プライベート関数を追加してCTE生成ロジックを集約
  - PARTITION BY に `keibajo_code` を含めて競馬場間のコース週番号混在バグを防止
- `src/mykeibadb_mcp_server/server.py`: MCPツールラッパー5関数に同パラメータを追加

## テスト内容

### 既存ファイルの変更

- `tests/test_high_level_api.py`: `course_kubun`/`week_in_course` 指定時の正常系テストを2件追加
